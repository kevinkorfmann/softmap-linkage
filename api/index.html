    API

    Main interface

    softmap.api.fit(data, marker_names=None, *, bootstrap=20, confidence=0.8, seed=1, bin_threshold=0.01)

    Fit a confidence-aware linkage map with practical defaults.

    Parameters

    data A :class:LinkageData object or an offspring-by-marker probability matrix. Values must lie between zero and one. marker_names Optional names when data is an array. bootstrap Number of bootstrap maps. Use at least 100 for a final analysis. confidence Minimum pairwise support used to select framework markers. seed Random seed for reproducible bootstrap results. bin_threshold Maximum expected disagreement for co-segregating marker bins. Pass None to select the threshold automatically.

    softmap.api.LinkageData dataclass

    Probabilistic marker data in offspring-by-marker orientation.

    shuffled(seed=1)

    Return a copy with marker columns in a reproducibly shuffled order.

    softmap.api.Map dataclass

    A fitted map together with the data needed for summaries and plots.

    ordered_markers property

    Marker names in inferred order.

    framework_markers property

    Names of markers whose relative order passes the confidence threshold.

    summary()

    Return a compact, serializable fit summary.

    marker_table()

    Return one inspectable result row for every input marker.

    Rows contain the marker name, co-segregation bin, inferred bin rank, representative status, optional framework rank, and bootstrap placement bounds. The return value uses only built-in Python types, so it can be printed directly or passed to a table library such as pandas.

    plot(path=None)

    Create the standard overview figure and optionally save it.

    plot_marker_order(path=None)

    Compare the input marker order with the fitted marker order.

    Example data

    softmap.datasets.demo(*, offspring=80, markers=60, seed=4)

    Return a small simulated backcross that runs in a few seconds.

    softmap.datasets.contemporary_hybridization(*, chromosome=1, markers=100, source=CONTEMPORARY_HYBRIDIZATION_URL)

    Load one chromosome from the Rahnamae et al. Arabis map.

    NN and SS calls become probabilities 0.01 and 0.99. NS and missing calls are represented as 0.5 because their phase is unresolved in this binary example. Markers are sampled evenly across the published map when markers is smaller than the available chromosome marker count.

    softmap.datasets.contemporary_map_positions(*, source=CONTEMPORARY_HYBRIDIZATION_URL)

    Load published physical and genetic coordinates for all eight chromosomes.

    Physical and genetic plotting

    softmap.plotting.plot_physical_vs_genetic(positions, path=None, *, colors=PHYSICAL_GENETIC_COLORS)

    Plot physical position against genetic position for every chromosome.

    softmap.plotting.plot_marker_order(mapping, path=None, *, colors=PHYSICAL_GENETIC_COLORS)

    Show the probability matrix before and after marker ordering.

    softmap.plotting.plot_physical_order_grid(mappings, path=None, *, colors=PHYSICAL_GENETIC_COLORS)

    Plot physical position against marker rank before and after ordering.
